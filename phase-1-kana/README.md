## 学习方法

1. **联想记忆**：每个假名都有形状联想（如「あ」=「安」的草书）
2. **书写**：每一行写5遍，注意笔顺
3. **听写**：我说你写，写完全部检查
4. **单词应用**：用学过的假名拼读日语单词
